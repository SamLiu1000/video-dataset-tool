A video editing tool specifically built and optimized for creating AI training datasets, designed to solve some of the biggest pain points when working with large video files.

### Key Features

- **Handle 20GB+ HDR videos** — Import and edit huge HDR videos directly while maintaining fast, real-time preview performance.
- **Flexible cropping & exporting** — Crop videos to any resolution and FPS, and export as video, images, or audio.
- **Precise timeline editing** — Quickly navigate to any point on the timeline and make frame-accurate cuts.
