这是一个**专门为 AI 训练集制作而设计的视频剪辑工具**，针对处理大型视频文件时常见的痛点进行了优化。

### 主要特点

- **支持 20GB+ HDR 视频** — 可以直接导入和剪辑 20GB 以上的大型 HDR 视频，同时保持快速、流畅的实时预览。
- **自由裁切与导出** — 可以按照任意分辨率和 FPS 对视频进行裁切，并导出为视频、图片或音频。
- **精准时间轴编辑** — 可以快速定位到时间轴上的任意位置，实现帧级精度的精细裁切。
